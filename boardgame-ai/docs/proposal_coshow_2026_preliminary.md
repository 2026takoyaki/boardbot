## 1. 아이디어 요약 (200자 이내 — 공백 포함 198자 검증 완료)

카메라 한 대가 실물 보드게임의 주사위·카드·손동작을 실시간 인식하고, 멀티에이전트 AI가 진행·심판·해설을 맡는 지능형 IoT 게임마스터 테이블. 룰을 몰라도 앉자마자 게임이 시작되고, 사회자가 필요한 게임도 전원이 플레이한다. 보드게임 산업의 '룰 장벽'을 없애고 시니어·장애인 놀이 접근성으로 확장하며, 교내 대회 수상으로 동작이 검증된 시스템이다.

## 2. 아이디어 개요 (1page)

### 제안 배경 — 성장하는 시장, 성장을 막는 '룰 장벽'

글로벌 보드게임 시장은 2025년 158억 달러에서 2034년 393억 달러로 연평균 10.7% 성장이 전망되며(Fortune Business Insights, 2025), 시장조사기관들은 **보드게임 카페의 확산**을 핵심 성장 동력으로 꼽는다. 디지털 피로 시대에 "얼굴을 마주 보고 노는" 아날로그 여가가 다시 성장하고 있는 것이다.

그러나 이 시장에는 구조적인 병목이 있다. **보드게임은 '아는 사람'이 있어야 시작되는 콘텐츠**라는 점이다.

- **기업(보드게임카페) 이슈**: 카페 한 곳이 보유한 게임은 100종이 넘지만, 현직 직원조차 "4개월을 일해도 룰을 다 외우지 못한다"고 호소한다(구인·커뮤니티 후기, 2025). 룰 설명은 테이블당 10~30분의 무급 노동이 되고, 직원 교육 비용·설명 품질 편차·성수기 대기 문제로 이어진다. 손님 입장에서는 어려운 게임을 피하게 되어 카페의 콘텐츠 자산 대부분이 잠자게 된다.
- **지역사회 이슈**: 보드게임의 인지·사회성 증진 효과는 학술적으로 검증되어 치매안심센터·복지관·돌봄교실이 앞다퉈 보드게임 프로그램을 도입하고 있으나(KCI 등재 체계적 고찰, 2024), 정작 **룰을 알고 진행해 줄 사람**이 부족해 프로그램 상시 운영이 어렵다. 고령층의 디지털 역량은 100점 만점에 36.9점(NIA 디지털정보격차 실태조사)으로, 화면 기반 대안(태블릿 인지훈련 앱, 전용 로봇)은 새로운 학습 장벽과 고비용 문제를 낳는다.

### 목적 및 필요성

본 팀은 이 문제를 "보드게임을 디지털 화면으로 옮기는" 기존 접근이 아니라, 정반대로 **"디지털이 실물 보드게임을 시중들게 하는"** 방식으로 해결하고자 한다. 테이블 위 오버헤드 카메라 한 대와 엣지 AI가 게임의 상태(주사위 눈, 카드, 말)와 사람의 행동(손동작, 차례)을 동시에 인식하고, AI 게임마스터가 음성으로 진행·심판·코칭·분위기 연출까지 수행한다. 사람은 아무 기기도 착용하지 않고, 아무것도 배우지 않고, 평소처럼 게임하면 된다.

이는 대회 주제인 '지역사회·기업 이슈 연계 지능형 IoT 솔루션'에 정확히 부합한다 — **기업 이슈**(보드게임카페·퍼블리셔의 룰 장벽 비용)를 1차 시장으로 해결하고, 동일 플랫폼을 **지역사회 이슈**(고령층 인지 프로그램, 장애인 놀이 접근성)로 확장한다.

*(중요) 본 시스템은 아이디어 단계가 아니다. 요트다이스·한밤의 늑대인간 2종을 완주 가능한 수준으로 이미 구현하여 교내 IoT 경진대회(WITHUS)에서 수상하였고, 본 대회에서는 완성도 고도화와 현장 실증을 수행한다.*

## 3. 핵심 아이디어 및 차별성 (최대 2page)

### 3-1. 시스템 개요

`[그림 1] 시스템 구성도 — 오버헤드 카메라 → 실시간 인식 파이프라인 → 게임 규칙 엔진(FSM) → 멀티에이전트 → TTS·조명·화면`

테이블 상단 카메라 1대 + 엣지 PC + 스피커 + IoT 조명 + 태블릿(점수판·보조 UI)으로 구성된다. 별도 전용 게임판·센서 내장 말·웨어러블이 **필요 없다** — 시중에 파는 보드게임을 그대로 테이블에 올리면 된다.

| 계층 | 역할 | 핵심 기술 |
|---|---|---|
| 인식 (Vision) | 주사위 눈·카드 종류·게임 말 + 손 제스처·좌석(누가 했는가)을 통합 인식 | 커스텀 학습 YOLO, 다중 객체 추적(ByteTrack), MediaPipe 손 랜드마크, 좌석-행위자 매칭 |
| 판단 (Rules) | 게임별 규칙 엔진이 상태를 관리하고 반칙·차례를 판정 | 게임별 FSM + 이벤트 융합 엔진(오인식 방어 3중 필터) |
| 진행 (Agents) | 역할이 다른 AI 에이전트들이 우선순위 중재로 협업 | 진행자(내레이션)·심판(반칙 경고)·템포(시간 관리)·전략 코치(LLM) 4-에이전트 |
| 연출 (IoT) | 음성·효과음·배경음악·조명이 게임 국면에 반응 | 3계층 TTS 캐시(지연 최소화), 우선순위 오디오 큐, IoT 조명 씬 |

### 3-2. 핵심 기능 4가지

1. **룰 러닝커브 제거**: 처음 하는 게임도 AI가 단계별로 안내하는 튜토리얼 모드로 즉시 시작. 점수 계산·차례 관리 전자동(요트다이스 구현 완료).
2. **사회자 필요 게임의 전원 참여화**: '한밤의 늑대인간'처럼 진행자 1명이 게임에서 빠져야 하는 게임을, AI가 사회자를 맡아 **전원이 플레이어로 참여**하게 만든다(구현 완료). 이 카테고리(마피아류·파티게임)는 카페 단체 손님의 핵심 수요다.
3. **실시간 심판**: 차례가 아닌 사람의 개입, 주사위 이탈, 잘못된 행동을 카메라가 감지해 즉시 음성 경고. 애매한 판정으로 인한 다툼을 중립적 제3자(AI)가 해소.
4. **게임 공간 연출**: 페르소나를 가진 AI 진행자의 음성 + 상황 반응형 BGM/효과음 + IoT 조명(밤 페이즈는 어둡게, 족보 완성 순간 플래시)으로 '진행자 있는 게임 방송' 같은 경험 제공.

### 3-3. 차별성 — 기존 접근과의 비교

| 구분 | 기존 접근 | 본 시스템 |
|---|---|---|
| 디지털 보드게임 앱 | 물성·대면 상호작용 상실, 화면 몰입 | **실물 게임 그대로** — 디지털은 보이지 않는 곳에서 시중 |
| 전용 스마트 게임판/센서 내장 기기 | 게임당 전용 하드웨어, 고비용 | 범용 카메라 1대로 **시판 게임 무개조 지원** |
| 인지훈련 로봇(예: 그룹형 훈련 로봇) | 수천만 원대, 전용 화면 콘텐츠를 새로 배워야 함 | 수십만 원대 구성, **어르신이 이미 아는 놀이** 그대로 |
| 룰 설명 영상/챗봇 | 결국 사람이 읽고 익혀서 진행해야 함 | 진행 자체를 AI가 수행 — **읽을 필요가 없음** |

**창의성의 핵심은 '발상의 방향'이다.** 지금까지의 기술은 보드게임을 화면 속으로 데려갔다. 본 시스템은 반대로 AI를 테이블 밖에 세워, 보드게임이 가진 본연의 가치(물성, 눈맞춤, 웃음)를 **하나도 훼손하지 않으면서** 진입장벽만 제거한다. 또한 단일 AI가 아닌 **역할 분담형 멀티에이전트**(심판은 단호하게, 진행자는 유쾌하게 — 목소리와 성격이 다름)와 **무버튼·무웨어러블 멀티모달 인식**(객체+모션+공간을 카메라 하나로)은 기술적 신선함을 더한다.

### 3-4. 문제 해결 접근 방식 — 비용 구조를 직접 겨냥

'룰 장벽'이 만드는 3가지 비용에 기능을 1:1로 대응시켰다: ① 직원 룰 교육·설명 노동 → AI 진행·튜토리얼(기능1) ② 진행자 부재로 못 여는 게임 → 전원 참여화(기능2) ③ 판정 분쟁·운영 품질 편차 → 실시간 심판(기능3). 효과는 카페 현장 파일럿에서 **룰 설명 소요 시간, 신규 게임 시도율, 테이블 회전율** 3개 지표로 정량 검증한다(4장 일정 참조). 기술 확장 역시 접근이 구조적이다 — 인식기(주사위·카드·손)는 공용 모듈, 게임 규칙은 플러그인으로 분리된 아키텍처라 **신규 게임을 '게임 팩' 단위로 추가**할 수 있으며, 이는 곧 수익 모델(게임 팩 스토어, 퍼블리셔 신작 튜토리얼 제휴)이 된다.

`[그림 2] 실제 시연 사진 2장 — (좌) 요트다이스: 주사위 인식·자동 점수 기록 화면 / (우) 늑대인간: 역할 카드 인식·밤 페이즈 진행`

## 4. 구현 가능성 및 기대효과 (1page)

### 4-1. 구현 가능성 — "만들 수 있는가"가 아니라 "이미 동작한다"

- **동작 검증**: 요트다이스·한밤의 늑대인간 2종 게임을 좌석 등록부터 승패 판정까지 완주 가능한 수준으로 구현 완료. 교내 IoT 경진대회(WITHUS) 수상. 자동화 테스트 197건 통과, 인식률·응답지연 자체 벤치마크 체계 구축.
- **기술 스택(전부 팀이 직접 구현·운용 중)**: 커스텀 YOLO 학습(주사위·트레이·역할카드 13종), ByteTrack 다중 추적, MediaPipe 제스처(V사인·OK사인·집기), 손목-좌석 매칭으로 행위자 식별, 게임별 FSM·이벤트 융합 엔진, 4-에이전트 오케스트레이터(LLM 전략 코치 포함), Google Cloud TTS 3계층 캐시(고정 멘트 지연 0초), WebSocket 실시간 통신, React 태블릿 UI.
- **잔여 개발이 아닌 '고도화' 일정**: (8월) 시연 안정화·AI 진행자 페르소나·상황 반응 LLM 멘트 (9월) 보드게임카페 현장 파일럿 1호점 + 지표 측정, 3번째 게임 팩 시험 이식(플러그인 구조 실증) (10월) IoT 조명 연출 완성·예선 발표 준비 (11월) 본선 현장 시연. 4인 팀 역할 분담 확립(비전 2·게임엔진 2 — 전원 본 시스템 개발 경력 1학기+).
- **시연 리스크 대비**: 조도 변화 대응 파라미터 프리셋, 인식 실패 시 수동 보정 UX, 카메라 재연결 워치독 등 현장 사고 방어 설계 반영.

### 4-2. 기대효과

- **기업(1차 시장)**: 보드게임카페의 룰 설명 노동 제거 → 인건비 절감·회전율 개선·잠자던 게임 자산 활성화. 테이블 SaaS(기기 리스+구독), 게임 팩 스토어, 퍼블리셔 신작 'AI 튜토리얼' 제휴, 게임 소비 데이터 리포트의 4단 수익 모델. 연 10.7% 성장 시장에서 국내 퍼블리셔·카페 생태계와 동반 확장.
- **지역사회(확장)**: ① **고령층** — 치매환자 100만 명 시대(2026, 보건복지부), 복지관·치매안심센터의 보드게임 인지 프로그램을 진행 인력 걱정 없이 상시화하고, 장기요양 평가에 필요한 프로그램 운영 기록을 자동 생성(복지사의 행정 부담 경감·대체가 아닌 보조) ② **시각장애인** — 게임 상황을 실시간 음성 중계하는 본 시스템의 특성상 접근성 도구로 자연 확장 ③ **발달장애 아동** — 일관된 규칙 안내와 구조화된 진행으로 사회성 놀이 치료 보조. 지역 복지기관·컨소시엄 지자체(제주) 연계 실증을 추진한다.
- **교육·확산**: 비전·엣지AI·멀티에이전트·IoT를 하나의 실물 서비스로 통합한 사례로서 사업단 교육과정의 실무 성과 모델 제시. 전 과정 오픈 아키텍처 문서화로 후속 팀 재사용 가능.

*"기술이 놀이를 대체하는 것이 아니라, 기술이 물러서서 사람들이 더 잘 놀게 만든다" — 본 팀이 제안하는 지능형 IoT의 모습이다.*
