# 1부. 요트다이스 — "카지노 중계" 만들기

## 현재 체감 진단 (코드 확인 기준)

| 순간 | 현재 | 문제 |
|---|---|---|
| 족보 완성(Yacht 50점!) | 일반 점수와 동일한 900ms 행 플래시 + 공용 score_select SFX | **게임 최고의 순간이 1점 기록과 똑같음** |
| 찬스 상황(요트까지 1개) | 아무 반응 없음 | 긴장감 빌드업 부재 |
| 한 바퀴 종료 | "라운드 N/12" 텍스트만 갱신 | 중간 서사·순위 변동 인지 없음(리더보드는 수동 모달) |
| 상단 보너스 63 달성 | 배지 텍스트만 +35로 변경 | 마일스톤인데 무음 |
| 게임 종료 | 정적 패널("OO님 승리!" + 점수 나열) | 시상식 없음 — 허무하게 끝남 |
| 주사위 표시 | 숫자 텍스트 버튼 | 인식 순간의 손맛 없음 |

## Y-1. 족보 완성 연출 — 티어별 차등 (P0)

- [ ] **티어 정의**: S = yacht(50) / A = large_straight(30)·full_house·four_of_a_kind / B = 일반 기록 / Z = 0점 기록(포기)
- [ ] **백엔드**: `_handle_score_category`에서 기록 확정 시 state_update payload에 `score_highlight: {category, tier, score, player_id}` 1회성 필드 추가(다음 update에서 제거). FSM이 족보명·점수를 이미 알고 있어(`_CATEGORY_TTS_LABELS`) 계산 로직 불필요.
- [ ] **연출 매핑**:
  - S: EXCITED_VOICE 외침 **"요트!!!"**(EXCITED_LINES 등록→부팅 prewarm 0지연) + 팡파레 SFX + 풀스크린 황금 컨페티(2.5s) + IoT 조명 골드 플래시 + BGM 순간 덕킹 → 이어서 "OO님, 요트! 50점입니다!" NORMAL 멘트
  - A: 족보명 외침("라지 스트레이트!") + 중형 파티클 + 조명 화이트 펄스 1회
  - B: 현행 유지(900ms 플래시 + score_select)
  - Z: 위로 멘트 풀 3~4개 로테이션("아쉽지만 다음 기회에…") + 낮은 트롬본 SFX — **웃음 포인트**
- [ ] 프론트: `recentScore` 확장 → tier 수신 시 파티클 레이어(포털) 렌더. 현행 1.1s 하이라이트를 S/A는 2.5s로.

## Y-2. 찬스 콜아웃 — 긴장감 빌드업 (P1, 시연 킬러)

- [ ] 굴림 확정 시 세션에서 조합 분석(프론트 previewScore 로직을 백엔드로 이식 or dice_values 카운트만):
  - 같은 눈 4개 + 남은 굴림 ≥1 → **"잠깐… 요트까지 단 하나 남았습니다!"** (HIGH priority) + 드럼롤 SFX + 조명 딤
  - 연속 4개 + large_straight 미기록 → "라지 스트레이트가 눈앞입니다!"
  - 이후 성공 시 Y-1 S/A 연출이 터지고, 실패 시 "아깝습니다!" — **빌드업→해소 구조**가 재미의 핵심
- [ ] 구현 지점: yacht_session `dispatch_vision_event`의 ROLL_CONFIRMED 처리 후 조건 검사 → `enqueue_tts`(HIGH) + `enqueue_sfx`. FSM 무변경.

## Y-3. 라운드·보너스 마일스톤 (P0)

- [ ] **한 바퀴 종료 브리핑**: `advance_player` 후 전원의 기록 수가 동일해지는 시점(=라운드 종료)에 "N라운드 종료! 현재 1위 OO님 XX점, 2위와 Y점 차이입니다" TTS + **리더보드 3초 자동 오버레이**(프론트 `leaderboardOpen` 자동 토글). 순위·점수차는 세션이 state.players로 계산.
- [ ] **상단 보너스 63 달성**: 달성 순간 "+35 보너스!" 전용 SFX + 배지 팝 애니메이션 + 멘트. (임박 연출: 60~62점 도달 시 배지 흔들림 + "보너스까지 N점!")
- [ ] **마지막 라운드 진입**: "마지막 라운드입니다. 순위가 뒤집힐 수 있습니다!" + BGM 텐션 트랙 교체(BGM_REGISTRY에 `yacht_final` 추가) + 조명 미세 상승.
- [ ] **역전 가능 콜아웃**: 최종 라운드에서 현재 플레이어의 최대 획득 가능 점수 ≥ 1위와의 점수차이면 "이번 선택으로 역전 가능합니다!" (계산: available_categories × previewScore 최댓값 — scoring.py 재사용).

## Y-4. 시상식 연출 — GAME_END 개편 (P1)

- [ ] 현행 정적 패널 → **3단계 시퀀스**: ① 드럼롤 + "오늘의 우승자는…" ② 3위→2위 순차 공개(점수 카운트업 애니메이션) ③ 우승자 공개: 팡파레 + 컨페티 + 조명 `result` 씬 + EXCITED "우승!"
- [ ] **AI 총평 리캡**(LLM, 페르소나 트랙과 연동): "오늘의 명장면은 8라운드 OO님의 요트였습니다" — 세션이 기록 이력(라운드별 score 기록)을 프롬프트로 전달. 실패 시 템플릿 폴백("최고 득점 한 방: OO님의 XX YY점"은 규칙 기반으로도 산출 가능).
- [ ] sequence_id 직렬화(AudioManager 기지원)로 드럼롤→발표→팡파레 순서 보장.

## Y-5. 손맛·피드백 디테일 (P0~P1)

- [ ] **주사위 pip 렌더**: 숫자 텍스트 → CSS 도트 주사위(⚀~⚅ 스타일). 굴림 인식 확정 순간 **슬롯머신 롤 애니메이션**(0.4s 랜덤 눈 회전 후 확정값 정지 + 틱 SFX) — `roll_count` 증가 감지 시 트리거(프론트만으로 구현 가능).
- [ ] **인식 상태 라이브 배지**: AWAITING_ROLL 중 "주사위 감지 3/5…" 표시. 구현: 파이프라인 `phase_hints.dice_count`를 1초 스로틀로 세션에 중계(신규 경량 이벤트 or 디버그 스냅샷 폴링). 인식이 늦는 날에도 "시스템이 보고 있다"는 안심을 줌 — **인식률 체감 보완 장치**.
- [ ] 킵 토글 시 딸깍 SFX + 킵존 주사위 살짝 띠오르는 애니메이션.
- [ ] 턴 전환 시 다음 플레이어 좌석 방향 화살표 1회 표시(TableVisualization 재사용 가능하면).

# 2부. 한밤의 늑대인간 — "준비는 빠르게, 밤은 의식처럼, 투표는 축제처럼"

## 현재 체감 진단 (타이밍 실측 기준)

**준비(역할 등록) 인당 비용**: 카드 스캔 TTS+인식 대기(성공 3~5s, 실패 시 **12s 타임아웃**) → 확인 화면(자동확정 7s 카운트다운, 저신뢰 시 수동) → 전환 화면(안내 TTS ~4s + 고정 3s, 데드라인 9s). **인당 15~25초 × N명 + CardSetupGuide(문장당 타이핑 60ms/자 + 홀드 5s ≈ 8~9초 × 문장 수)** → 6인 기준 준비만 2~3분, 그동안 나머지는 눈 감고 무음 대기. **카드 인식이 안 되는 판에는 12초 침묵이 반복**되는 구조가 루즈함의 본체.

**투표 UI 어긋남(사용자 보고 + 코드 확인)**: VoteCountdown 페이지가 `justify-content:center` 세로 플렉스인데 카운트다운 숫자(96px)가 조건부 삽입 → **등장 순간 타이틀·안내·카드 그리드 전체가 아래로 점프**. 카드 그리드는 인원수 무관 4열 고정(5~6인 시 2행) + `100vh overflow:hidden`이라 카운트다운과 겹치면 하단 클리핑 가능.

## W-1. 준비 단계 페이싱 개편 (P0 — 지목하신 핵심)

- [ ] **"직접 선택" 상시 노출**: RoleRegShowCard 하단에 역할 그리드 버튼을 처음부터 표시(현재는 12초 타임아웃 후에만 진입). 인식이 빠르면 자동, 안 되면 즉시 탭 — **최악 대기 12초 → 0초**.
- [ ] **타임아웃 12→7초 단축** + 카운트다운 문구를 "7초 후 직접 선택으로 전환" → "카드가 인식되지 않으면 아래에서 직접 선택하세요"로 변경(수동이 실패가 아니라 정상 경로처럼 느껴지게).
- [ ] **인식 라이브 피드백**: 카드 bbox는 잡히는데 역할 분류가 미확정인 상태를 화면에 반영 — "카드 감지됨, 조금만 고정해주세요" / 미감지 시 "카드를 조금 더 가까이". 구현: werewolf_rules에 저신뢰 중간 이벤트 `ROLE_DETECTING`(1초 스로틀, role 미포함) 추가 → 세션 → role_reg payload에 `detecting: true`. **인식률이 그대로여도 답답함이 절반으로 줄어드는 항목**.
- [ ] **전환 화면 단축**: 안내 문구를 "카드를 엎고, 눈을 감아주세요"로 단축(TTS ~2.5s), 고정 3s 텀 → CARD_PLACED_DOWN 감지 시 1.5s(백엔드 `REG_CARD_PLACED_ADVANCE` 상수 조정으로 끝), 미감지 폴백 데드라인 9→6s. 전환 화면에 **다음 플레이어 이름 미리 표시+호명**("다음은 OO님입니다") — 다음 사람이 미리 준비해 스캔 시작이 빨라짐.
- [ ] **CardSetupGuide 압축**: 타이핑 60→35ms/자, 홀드 5000→3000ms, **화면 탭으로 문장 스킵** 추가. 오프닝 총 소요 30~40% 단축.
- [ ] **대기의 재프레이밍 — "밤의 의식" 연출**: 등록 루프 동안 저볼륨 서스펜스 앰비언트(BGM_REGISTRY `werewolf_prep`) + 등록 진행을 **달이 차오르는 그래픽**(N/전체)으로 표시 + 2~3명마다 분위기 내레이션 1줄("마을에 안개가 깔리기 시작합니다…" — STATIC_LINES 등록, 캐시 0지연). 대기가 "지루한 줄서기"에서 "게임이 이미 시작된 느낌"으로 바뀜.
- [ ] (검토) **일괄 등록 모드**: 전원이 동시에 자기 카드를 좌석 앞에 앞면으로 3초 놓기 → CardTracker의 좌석 매핑으로 동시 인식 → 일괄 확인 화면. 준비 시간이 N배→1배로 줄지만 "옆 사람 카드 노출" 리스크가 있어 **가림판 제공 또는 튜토리얼 전용**으로 실험 후 결정.

## W-2. 투표 단계 — UI 버그 수정 + 연출 (P0)

- [ ] **(버그) 레이아웃 점프 수정**: 카운트다운 숫자 자리(높이 ~100px)를 항상 예약(placeholder)하거나 absolute 오버레이로 전환 — 등장/소멸 시 타이틀·그리드가 움직이지 않게. *(improvement_plan F-2에도 등재)*
- [ ] **(버그) 그리드 반응형**: `repeat(4,1fr)` 고정 → 인원수 기반(3인=3열, 4인=4열, 5~6인=3열2행) + 6인+카운트다운 상태에서 100vh 클리핑 없는지 태블릿 실기 검증.
- [ ] **지목 반영 순간 피드백**: 비전 포인팅이 잡히는 즉시 해당 카드에 화살표 스탬프 애니메이션 + 짧은 "척!" SFX — 지금은 뱃지 텍스트만 바뀌어 "인식됐는지" 확신이 안 듦(포인팅 인식 체감 보완).
- [ ] **결과 공개 연출**: VoteResult를 "즉시 전체 공개" → **드럼롤 후 득표 적은 순 순차 공개, 최다 득표자 마지막**(1초 간격 플립) + 최다 득표자 공개 시 붉은 조명 펄스 + "가장 많은 지목을 받은 사람은… OO님!" TTS. 동률이면 "동률! 운명의 장난입니다" 분기.
- [ ] 카운트다운 숫자 TTS("오,사,삼…")는 유지하되 심장박동 SFX 레이어 추가(고조).

## W-3. 밤 페이즈 몰입 (P1)

- [ ] **역할별 사운드스케이프**: 페이즈 진입 SFX 차등 — 늑대(하울링, 기존), 예언자(신비 차임), 도둑(살금살금 발소리), 말썽꾼(장난스런 효과음)… SFX_REGISTRY 추가 + `_enter_phase`에서 발화. 눈 감은 플레이어들에게 소리가 유일한 채널이므로 **가성비 최고 몰입 장치**.
- [ ] **행동 완료 공용 신호 통일**: 카드 감지로 페이즈가 넘어갈 때 항상 같은 "딩—" 차임(눈 감은 사람들이 "진행되고 있구나"를 인지, 특정인 정보는 노출 안 됨).
- [ ] **액티브 페이즈 타임아웃 유연화**: 12s 고정 강제 전이 → 미감지 시 "시간이 얼마 남지 않았습니다"(TempoAgent phase_end_warning 기존 인프라) 후 **1회 +5s 연장**, 그래도 없으면 전이. 행동을 놓쳐서 게임이 깨지는 억울함 방지.
- [ ] IoT 조명 연동(개선계획 D): 밤=딥블루 저조도(단, 카드 인식 최소 조도 하한 클램프), 아침 전환=웜 화이트 페이드인 — NightEnd의 "아침이 밝았습니다"와 동기화.

## W-4. 낮 토론 활성화 (P1)

- [ ] **AI 사회자 화두 3종**: 토론 시작 "간밤에 누군가는 거짓말을 준비했습니다. 첫인상부터 말해볼까요?" / 중반(50% 경과) "지금까지 한 마디도 안 하신 분, 수상합니다?" / 종반 30초 전 "곧 투표입니다. 마지막 변론을!" — TempoAgent `_MILESTONES` 문구 교체 + werewolf 전용 마일스톤 셋 추가(현재 범용 "절반의 시간이…"에서 게임 맥락 문구로). LLM 페르소나 적용 시 변형 풀 생성.
- [ ] 기본 토론 시간 300s → **180s 기본 + 30s 연장 버튼 유지** 검토(파티 템포 기준, 플레이테스트로 확정).
- [ ] 남은 30초 심장박동 BGM 레이어 + 링 타이머 붉은 펄스(isUrgent 기존 스타일 강화).

## W-5. 게임 종료 — 반전 공개 리캡 (P1, 이 게임 최고의 순간)

- [ ] **밤 행동 타임라인 재생**: 결과 화면에서 승패 발표 후 "그날 밤 실제로 일어난 일" 순차 공개 — "도둑 OO가 XX의 카드를 훔쳤습니다 → XX는 사실 늑대인간이 되어 있었습니다…" 카드 플립 애니메이션 + 내레이션. 데이터는 FSM night_roles resolve 시점에 이미 결정돼 있으므로 `state.night_log` 리스트로 축적만 하면 됨(FSM 소폭 수정).
- [ ] **승리팀별 연출 차등**: 마을 승리=새벽 팡파레+웜 조명 / 늑대 승리=하울링+붉은 조명+로고 스탬프 / 무두장이 단독 승리=레코드 스크래치+코믹 연출("모두가 속았습니다!").
- [ ] 한 판 더 흐름 단축: 같은 인원 재시작 시 CardSetupGuide 풀 안내 스킵(요약 1문장만) — 재판 진입 마찰 제거.

# 3부. 공통·실행

- [ ] **연출 에셋 제작 목록**: SFX 8종(팡파레·드럼롤·트롬본·차임·심장박동·발소리·딸깍·척), BGM 2종(yacht_final, werewolf_prep), 파티클 컴포넌트 1종(재사용). 무료 라이선스 소스(freesound 등)로 1일 작업.
- [ ] **연출 과다 방지 원칙**: 티어 S/A급 연출은 판당 평균 1~3회 나오는 이벤트에만. 매 턴 나오는 이벤트(B)는 0.5s 이내 피드백으로 제한 — 소음 피로 방지. TTS는 우선순위 큐가 이미 중복을 관리하므로 연출용 멘트는 전부 interruptible=True로.
- [ ] **플레이테스트 프로토콜**: 팀 4인 실플레이 각 게임 2판 — ① 준비 소요시간(늑대인간 목표: 6인 90초 이내) ② "지루했던 순간" 각자 3개 기록 ③ "웃었던/소리 지른 순간" 기록 → 다음 이터레이션 반영. 개선 전 1회 측정해 **전/후 수치**를 확보(공모전 발표 자료로 재활용).
